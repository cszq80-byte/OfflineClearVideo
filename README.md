# OfflineClearVideo v0.7 — 离线视频 AI 增强：纹理强度与本地对比

## 针对皮肤、衣服细节的更新
- **自然/均衡/明显** 三档 AI 效果。自然混合原始插值与 Real-ESRGAN 输出，降低假毛孔、假纤维风险；均衡保留 v0.6 模型输出；明显轻度增加模型与原片之间的细节差异，可能产生假纹理。
- **更高导出码率**：高画质 Real-ESRGAN 模式按分辨率和帧率动态提高 H.264 编码预算；不支持高码率的编码器会回退到原码率。提高码率仅减少进一步压缩，不会恢复已丢失的细节。
- **本地前后对比**：成功导出后，点击“查看上次导出”进入无网络帧对比界面，同时间点左原片、右结果；可拖动分界、选择时间和同步放大检查皮肤或布料。
- 沿用 v0.6 前台任务与取消通知，切出 App 不会因为 Activity 销毁主动取消任务。
- 输入和输出仍由系统选择器授权，不申请互联网权限；所有帧在设备本地读取与显示，不上传。
- **目前不含皮肤人体分割、光流时序稳定或专用毛孔重建模型**，不保证对失焦、严重压缩的视频明显改善。细节“明显”档可能生成假纹理。请在原手机使用内置对比确认。

## 使用步骤
1. 保留原视频不变；使用 720P 或以下片源，选高画质 Real-ESRGAN 模式。
2. 选择自然、均衡或明显，首先使用 2-5 秒片段处理。模型 CPU 推理很慢。
3. 等处理完成后，点“查看上次导出”，拖动中间分割线并局部放大，比较皮肤纹路、布料褶皱的真实性。
4. 如果新旧差异不够或出现假纹理，调整强度再导出比较；效果不改善就不建议继续增强调强度。

## 兼容性与限制
Android 8.0+，调试签名 APK 需可能先卸载旧版。不同编解码器与 ColorOS 后台策略会影响速度和可靠性。Real-ESRGAN 4 倍输出再缩小到 2 倍，用于减少内存。适用输入最长边 1280、短边 720（包括竖屏）。可能丢失不兼容音轨。HDR / DRM 不支持。最终画质必须由用户设备上的原片实测，不对结果作夸大保证。

## 无原视频的算法基准
构建时自动生成无真人数据的合成皮肤与编织布料纹理，并在同一 2 倍显示尺寸下比较普通 Bicubic 插值与 Real-ESRGAN；完整保留 AI 比普通插值更差的指标（如果出现），不会因为比较结果差而选择性隐藏样例。测试报告随 APK 构建工件附带。合成基准不是用户实拍视频的实际效果证明。
